# 追加機能の使い方

設定はSTUDIOから変更できます。手元で試すときは「このブラウザに反映」を押します。全員に公開するときは左側の「変更を反映する」を押してください。

## 進捗を指定して試す

「テスト・移行」の「進捗段階」に数字を入力して「この段階に変更」を押します。会話履歴や送信予約は残ります。最初から試したい場合は「全進捗をリセット」を使ってください。

## SNS投稿の並び順と固定表示

「発信内容」で種類を「SNS投稿」にします。

| 項目 | 使い方 |
| --- | --- |
| 段階0の表示順 | 1、2、3…と指定すると初期ホームにその順で並びます。空欄の投稿はその後にランダムで入ります。 |
| ホームに固定する段階 | `3, 5, 8` のように指定します。その段階のときだけ固定します。 |
| ホームの固定位置 | 上から何番目に置くかを1〜10で指定します。同じ段階で同じ位置は使えません。 |
| 投稿時期 | プロフィール内の順番に使います。数字が小さいほど新しい投稿になります。日時そのものは表示しません。 |

ホームは最大10件です。固定投稿を先に確保して残りを選びます。公開前や削除済みの投稿は固定していても出ません。投稿数が固定位置より少ないときは空白を作らず末尾に表示します。

「投稿を削除」で選択中の投稿を削除できます。その投稿についた返信もまとめて削除します。引用元や自動返信の対象に使っていた場合はその設定も解除されます。

## SNSの返信・検索・DM

NPCの返信は「発信内容」の「返信先ポスト」で指定します。返信をさらに返信先に選ぶこともできます。プレイヤーは返信欄の「返信する」から返答できます。キーワードへの自動返信は「SNS設定」の「自動返信」で設定します。

プロフィールには他の投稿への返信も含めて新しい順に表示します。アイコン画像は押すと拡大します。ID検索は最後まで入力したときにアカウントが見つかります。アカウント名や投稿文の検索も引き続き使えます。

DMは最初は空です。プロフィールの「メッセージ」から相手との会話を開きます。返信が設定されたキーワードを送ると「入力中」が表示されて10秒後に返信が届きます。連絡先追加リンクや別サイトへのリンクは新しいタブで開きます。

## LINE風サイトの予約返信と音声

「会話シナリオ」の「予約返信を追加」で予約を増やせます。「時間の起点」でキーワード送信時か前の予約返信の予定時刻を選びます。

たとえば1通目を「翌日の指定時刻・19時」、2通目を「前の予約返信の予定時刻・指定秒数後・60秒」にすると翌日19時と19時1分に届きます。各予約で送る相手と段階を進めるかを選べます。

通常の返信にも予約返信にも「MP3を添付」から音声を選べます。1ファイル10MBまで、1通に20ファイルまで添付できます。添付後は再生ボタンで試聴でき、×で外せます。最後に「変更を反映する」から公開してください。

TALKではファイル名を表示せず、再生・一時停止のボタンだけを表示します。音声は共通保存先に保存されるので、別の端末でも聞けます。従来の音声パスも「音声パスを指定」から入力できます。

作品のページが画面に出ていない間は送信処理を休止します。戻ると予定時刻を過ぎた予約が届きます。同じ相手からの返信は間隔を空けて届きます。NPCの文章は「コピー」でまとめてコピーできます。

返信の処理待ちが長引いた場合は自動で再試行します。再読み込みの案内が出たら作品のほかのタブを閉じてから押してください。進捗は残ります。

ルール一覧の「並び順」を「ルール名の昇順」にすると名前順に探せます。

## ショッピングサイトの出品者チャット

STUDIOの「出品者チャット」で「ルールを追加」を押します。商品・キーワード・返信内容を設定してください。「完全一致」「いずれかの言葉を含む」「どんな入力にも返信」を選べます。

プレイヤーは商品ページの「出品者とのチャット」から送信します。設定に合ったときだけ返信します。会話は商品ごとに保存されます。

## 表示の変更

ファンクラブのブログとサロンの記事はNoto Sans JPで表示します。行間は文字サイズの1.5倍です。サロン本文は18pxにしました。

VS-402Lの声紋プロファイル欄は削除しました。秘密の質問には「アメスピ」「アメリカンスピリット」「アメリカン・スピリット」「ナチュラルアメリカンスピリット」「ナチュラル・アメリカン・スピリット」のどれでも進めます。製造番号も必要です。

## QRコード

[QRコード一覧](../qr/)からSNS・メッセージ・ショッピングの画像を保存できます。印刷にも使えるSVG版もあります。現在の公開先へのQRコードなのでドメインを変える場合は作り直してください。
